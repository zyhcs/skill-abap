# 12. 常见异常诊断与故障排查指南 (Troubleshooting Matrix)

本文档列举了在使用 `sap-ai-mcp-rest-api` 过程中可能遇到的常见故障现象、根因分析与对应的处置方案。

---

## 常见故障排查表

| 故障现象 | 阶段 / 错误码 | 根因分析 (Root Cause) | 处置方案 (Action) |
| :--- | :--- | :--- | :--- |
| **HTTP 401 Unauthorized** | 认证阶段 | 用户名/密码错误，或目标 SAP Client 无权限 | 检查 `sap_environments.json` 中的 `user`/`password` 或环境变量设置，确认 SAP 账号解锁 |
| **HTTP 404 Not Found** | ICF 路由阶段 | 1. SICF 节点未激活；<br/>2. ICF URL 拼写或大小写不正确 | 1. 在 SAP 中执行事务码 `SICF` 激活 `/sap/bc/zai_mcp_rest`；<br/>2. 检查 URL 保证路径全小写 `zai_mcp_rest` |
| **`ENVIRONMENT_WRITE_FORBIDDEN`** | 客户端防线拦截 | 尝试在 `qas` 或 `prd` Profile 下调了 `mode: "write"` 端点 | 若确实需要写操作，需切换至 `dev` Profile，或确认环境配置文件中的 `allow_write: true` |
| **`SYNTAX_CHECK` 报错 `"U0027..."`** | 语法检查阶段 |  JSON 序列化工具把单引号 `'` 转义为了 `\u0027`，导致 ABAP 误解析 | 在客户端 JSON 拼接后执行 `-replace '\\u0027', "'"` 替换回标准单引号 |
| **`SELF_MODIFICATION_FORBIDDEN`** | 后端防线拦截 | 尝试通过 REST 接口更新 `ZCL_AI_MCP_REST_FUN` 类本身 | 属于系统自我保护。核心 Handler 类的更新必须在 SAP GUI (SE24) 中手工导入激活 |
| **DDIC 激活失败: Reference Table Missing** | DDIC 创建阶段 | `CURR` (货币) 或 `QUAN` (数量) 字段缺少引用的参考表/字段 | 在字段中配置 `ref_table` 和 `ref_field`，或使用 `DEC` 13 (Decimals 2) 替代纯 `CURR` 字段 |
| **`SELECT` 查询结果为空** | 动态执行阶段 | 数据表中尚未插入数据，或 `sy-mandt` 客户端不匹配 | 在执行程序中加入自动判断 `SELECT COUNT(*)`，若为 0 自动插入 `DEMO` 测试数据并执行 `COMMIT WORK AND WAIT` |

## 日志与诊断探针工具

调试时可使用 `scripts/sap_ai_mcp_debug.py`：
```bash
python scripts/sap_ai_mcp_debug.py --profile dev
```
此工具会自动检查目标 SAP 系统的连接状态、锁定对象 (`/debug/locks`) 与底层处理类版本。
