## 模块文档快照

1. **总览与上手**：适合新接触本 Skill 的开发者与 AI Agent 快速了解全局功能与连接配置。
2. **架构设计**：包含架构图、数据流向图及 Client/Server 通信全过程。
3. **规范控制体系**：企业级开发规范、命名规则、变量前缀及性能控制。
4. **底层实现**：详细拆解 9,400+ 行 ABAP REST 核心类 `ZCL_AI_MCP_REST_FUN.abap` 和 Python SDK 的函数层实现。
5. **SOP与排查**：各类型 SAP 对象的标准开发流程与常见问题解决方案。
